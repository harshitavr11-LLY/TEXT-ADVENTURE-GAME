# Text Adventure Game

## Description

This is a text-based adventure game developed using Python.

The player explores different locations like cave,rive,temple,castle, collects items, gains points, and searches for a hidden treasure and explore more

## Features

- Lost Jungle
- Cave
- River
- Temple
-  mystery Castle
- Inventory System
- Health System
- Score 

## Requirements

- Python 3.x

## How to Run

1. Open a terminal.
2. Go to the project folder.
3. Run:

```bash # use this to run the program
python main.py
```

## Game Objective

Explore different locationslike cave,river,castle,temple,inventory, collect useful items, and find the hidden treasure.
